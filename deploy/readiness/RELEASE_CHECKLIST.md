# Lista de liberación

- [ ] Commit y artefacto identificados.
- [ ] Pruebas automatizadas completas en verde.
- [ ] Configuración de producción validada sin secretos en repositorio.
- [ ] Respaldo y restauración verificados.
- [ ] Migraciones probadas y reversión documentada.
- [ ] Puerta de carga y seguridad aprobada en ambiente equivalente.
- [ ] Vulnerabilidades críticas/altas cerradas o aceptadas formalmente.
- [ ] Monitoreo, alertas y responsables de guardia verificados.
- [ ] Continuidad de urgencias ensayada.
- [ ] Cambio, comunicación y reversión aprobados.
